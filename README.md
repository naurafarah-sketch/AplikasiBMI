# Aplikasi Kalkulator BMI (JavaFX)

Aplikasi desktop sederhana untuk menghitung Indeks Massa Tubuh (Body Mass Index / BMI) berbasis JavaFX, dikembangkan menggunakan NetBeans IDE, Scene Builder, dan Apache Maven.

# Cara Menjalankan Aplikasi

1. **Clone Repository**
   ```bash
   git clone [https://github.com/naurafarah-sketch/AplikasiBMI.git](https://github.com/naurafarah-sketch/AplikasiBMI.git)

   1. Buka project di Apache NetBeans.
   2. Klik kanan project AplikasiBMI lalu pilih Clean and Build.
   3. Cari file BmiMain.java di package com.mycompany.aplikasibmi.
   4. Klik kanan BmiMain.java lalu pilih Run File (atau tekan Shift + F6).
